# Project layout

This project is a single-file web app. Keep `index.html` in the project root so GitHub Pages can serve it, alongside `AGENTS.md`, `spec.md`, and `prompts.md`.

- `00_planning/` — planning notes and sketches.
- `01_data/` — project data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate root file or numbered folder above; do not add files at the root unless they belong there.
